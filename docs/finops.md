# FinOps

Money is calculated with `Decimal`; every price has an effective date, source and version. The local catalog is an **estimated** demonstration, while GPU cost from the fixture is **simulated**. Unknown prices produce `PRICE_UNKNOWN`, never a silent zero.

Self-hosted model cost combines token activity with GPU-time allocation. Shared cost must state its allocation method (the first implementation uses token-weighted allocation); it is not an invoice.
